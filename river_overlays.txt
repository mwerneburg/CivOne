# river_overlays.txt  (v2 — natural rivers)
# Per-tile river overlays for CivOne. Replaces the saturated 1991 river sprites
# with cassette/wave-palette water, shaped to meander like a real river rather
# than a straight canal.
#
# Format: named 16x16 sections of palette indices, identical to free_tiles.txt /
# shore_waves.txt. 0 = transparent (terrain shows through).
#
# Water palette (shared with shore_waves.txt so both animate on one cycle):
#   66 = WAVE_BASE  channel bank            (28, 95,150)
#  100 = trough     darker bank fleck       (20, 70,120)
#   67 = WAVE_SURF  channel core            (130,200,230)
#   96 = WAVE_FOAM  current glint / surf     (210,235,248)
#   68 = WAVE_MID   delta blend to sea      (58,172,204)
#   47 = wet-sand   occasional pebbled bank (200,152, 96)
# Rivers sit LIGHTER than ocean (index 18) so freshwater reads distinct.
#
# NATURAL LOOK — what changed vs v1:
#   * bends are quarter-arc curves, not right-angle elbows
#   * straight reaches meander (a shallow bow / S-curve) off the tile centre
#   * banks are ragged: the 66 edge wanders +/-1px with 100/47 flecks
#   * channels taper (~2px on reaches) and widen into a point-bar at bends/hubs
#
# VARIANTS — straights (NS, EW) and bends (NE, ES, SW, NW) each ship TWO cuts,
# _a and _b, with different meander phase / arc tightness. The renderer should
# pick one per tile from a stable hash of the tile's map coordinates, e.g.
#     variants[(x*7 + y*13) & 0x7fffffff) % variants.length]
# so a long river never repeats the same segment but stays deterministic.
# All other pieces (endpoints, T-junctions, confluence) have a single cut.
#
# Every channel still crosses each tile edge dead-centre (cols/rows 7-8) and runs
# straight through the outer 1px ring, so ANY variant connects to ANY neighbour.
#
# Naming: river_<dirs> over the subset of N E S W (that order) carrying river.
#   river_isolated  spring        river_NS_a/_b straight    river_NE_a/_b bend
#   river_NES T-junction          river_NESW confluence
# River mouths fire on a river tile touching ocean; composite with shore_<dir>
# for surf. rivermouth_<dir> points the delta at the sea on that side.
