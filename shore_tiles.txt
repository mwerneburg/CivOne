# Wave palette quick reference (cycling range 96–103 in GamePlay):
#  96 = WAVE_FOAM  near-white surf crest   (brightest)
#  97 = WAVE_SURF  light cyan-blue
#  98 = WAVE_MID   mid-blue shallows (= CYAN ocean colour)
#  99 = WAVE_BASE  dark approaching wave
# 100-103 = dark trough phase (between waves, no named entries needed here)
#
# Assignment rule for "wave rolls TOWARD shore" with GamePlay's right-shift cycle:
#   Shore edge pixel → index 99   (receives foam last, after 3 cycle steps)
#   One pixel inward → index 98
#   Two pixels inward → index 97
#   Three pixels inward → index 96   (starts as foam, travels toward shore)
#
# Cardinal sections are composited: a tile with land N+W gets both shore_N and shore_W
# overlaid.  Diagonal-only sections (shore_NW etc.) fire only when no cardinal applies.
