Where everything in this repository came from. `ART-MANIFEST.txt` lists every
tracked binary asset with the date it first appeared; this file explains what
those files are and on what terms they are here.

## What is deliberately NOT here

**No original MicroProse Civilization I data files.** No `.PIC`, `.MAP`, `.SVE`
or other retail asset is tracked in this repository, and none is required to
build or play.

The engine can still *read* original DOS assets if a user supplies them from
their own copy of the game — that is how upstream CivOne worked. Everything
those files provided has a fallback here: bundled art, or art generated
procedurally at runtime (`src/Graphics/Free.cs`, `src/Graphics/Sprites/`). A
missing original asset degrades to the fallback rather than failing, and the
game is playable with no original assets at all.

## Art

189 binary assets are tracked. Two are upstream application icons from 2018
(`resources/linux/CivOne.png`, `resources/macos/CivOne.icns`, CC0 with the rest
of the upstream project). The remaining 185 were made for this fork between
May and August 2026:

| Directory | What it is |
|---|---|
| `data/improvement_art` | City improvement and wonder illustrations |
| `data/event_art` | Full-screen event and milestone art |
| `data/leader_art` | Leader portraits |
| `unit_tiles`, `garrison_icons` | Unit and garrison sprites |

These were produced by the project's author using generative image tooling and
hand editing, in a deliberately uniform amber-phosphor style, and are licensed
with the rest of the fork under GPL-3.0-or-later. They are not derived from,
traced from, or modified copies of any commercial game's artwork.

Note that the copyright status of purely machine-generated images is unsettled
in several jurisdictions and may vary with how much human authorship went into
a given file. The GPL grant here is made on the same terms as the rest of the
project; no stronger claim is intended.

## Map data

`resources/earth_epic.bin` and `resources/earth_standard.bin` are terrain grids
(320×200 and 80×50) generated by `design/build_earth_map.py` from public-domain
equirectangular elevation imagery — NASA Visible Earth topography or Natural
Earth cross-blended hypsometry, both public domain / CC0. The script records
the exact classification thresholds it applies; the imagery itself is not
redistributed here, only the derived terrain codes.

## Sound

No audio files are tracked. The engine plays sound only from user-supplied
original assets, and runs silently without them.

## Rebuilding the manifest

    tools/art-manifest.sh > ART-MANIFEST.txt

The manifest is generated from git, so it cannot drift from what is actually
shipped. Regenerate it when assets are added or removed.
